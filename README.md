# 바둑한수

하루 한 수씩, 바둑을 배우다 — 바둑을 처음 배우는 사람을 위한 개인용 아이폰 학습 앱(PWA).

- 주소(배포 후): https://yeons-play.github.io/baduk-hansu/
- 규칙 명세: [docs/rules.md](docs/rules.md)

## 진행 상황
| 단계 | 내용 | 상태 |
|---|---|---|
| 1-1 | 규칙 엔진 + 검증 테스트 | 완료 |
| 1-2 | 바둑판 화면, 1~6강, 따내기 바둑 AI, 진도 저장 | 예정 |
| 2 | 7~12강, 정규 대국 AI, 계가 화면 | 예정 |
| 3 | 기초 사활, 오답 복습, 해설, 기보 | 예정 |
| 4 | KataGo 실기기 실험 | 예정 |

## 규칙 검증 방식
1. 함정 사례 단위 테스트 — 따내기 판정 순서, 자살수, 패, 되따기, 빅 계가, 종료, 무르기
2. 무작위 대국 불변식 — 활로 0 그룹 없음, 돌 수 보존, 해시 일치, 판 모양 반복 없음
3. 교차 대조 — 같은 무작위 대국을 [@sabaki/go-board](https://github.com/SabakiHQ/go-board)에 넣어 매 수 결과 비교
