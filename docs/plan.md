- 이전 판: v1(아이폰·성인 초보 기준) → v2(검토 반영) → **v3(7살 어린이·아이패드 기준으로 전환)**

## 1. 목표와 사용자

### 1.1 목표
> 바둑을 처음 배우는 아이가 짧은 체험 강의로 규칙을 익히고, AI와 따내기 바둑부터 9·13줄 대국까지 혼자 해 볼 수 있는 앱

### 1.2 사용자·기기
| 항목 | 내용 |
|---|---|
| 주 사용자 | 바둑을 처음 배우는 **7살 어린이** 1명 (보호자가 옆에서 도움) |
| 주 기기 | **아이패드** (세로·가로 모두), 아이폰도 지원 |
| 형태 | PWA, Safari에서 "홈 화면에 추가" |
| 배포 | GitHub Pages: https://yeons-play.github.io/baduk-hansu/ (조직 `yeons-play`, 업무용 개인 계정 저장소와 분리) |
| 비용 | 월 0원 (서버·유료 API·앱스토어 없음) |

### 1.3 차별화 원칙
- 규모(문제 수, AI 강도)로는 기존 앱과 경쟁하지 않는다.
- **"왜 그런지 알려주는 앱"**: 정답보다 이유를 판 위에서 보여주고, 소리로 읽어 준다.
- **규칙이 절대 틀리지 않는 앱**: 레슨·AI·계가가 한 엔진, 한 규칙 명세만 따른다.

## 2. 확정 사항

| 구분 | 내용 | 근거 |
|---|---|---|
| 규칙 | Tromp-Taylor 기반, 자살수 금지, 판 모양 동형반복 금지, 면적 계가(사석은 들어냄), 덤 7 | 사석은 앱이 짐작하고 사람이 고침(실제 바둑과 같은 끝내기). 상세: `docs/rules.md` |
| 입문 방식 | 따내기 바둑(먼저 1개 잡으면 승리) → 정규 대국 | 계가 없이 조기 실전, 동기 유지 |
| 캐릭터 | 까망이(아이, 흑) · 하양이(AI, 백), 설정에서 이름 바꾸기 가능 | 이름표·결과 화면에만 얼굴, 판 위 돌은 깔끔하게. 아이 이름으로 바꾸면 조사·읽어 주기도 맞춤 |
| 글씨 | 주아(제목·버튼) + 고운돋움(본문), 앱에 포함 | 오프라인 표시, 아이 친화 |
| 말투 | 쉬운 말 먼저, 바둑 용어는 괄호 → 화면에 파란 "바둑 말" 꼬리표 | 예: 숨구멍(활로), 잡기(따내기) |
| 소리 | 돌 놓는 소리 등 효과음(합성), 글 읽어 주기(기기 한국어 음성), 각각 끄기 가능 | 7살은 긴 글 읽기가 어려움 |
| 화면 이동 | 아이폰·아이패드에서 history API 미사용, 아래 탭과 "← 뒤로"만 | 법ON 앱 방식 |
| 저장 | 기기 안(localStorage), 모든 키·캐시 `baduk-` 접두어 | 같은 주소의 다른 앱과 충돌 방지 |
| 문제 출처 | 입문 문제는 프로그램 자동 생성 + 엔진 판정, 사활은 직접 작성 + 탐색기 검증, 저작권 있는 문제집은 저장소에 넣지 않음 | 검수 주체 부재, 공개 저장소 |

## 3. 강의 계획 (7살 기준 12강)

한 강은 6~7단계, 5분 안팎. 각 단계는 설명 → 직접 눌러 보기 → 고르기로 구성하고, 정답은 규칙 엔진이 계산한다.

| 강 | 쉬운 이름(바둑 말) | 판 | 핵심 활동 | 상태 |
|---|---|---|---|---|
| 1 | 바둑판과 점(교차점) | 9줄 | 천원·화점 찾기, 돌은 점 위에 | 완료 |
| 2 | 번갈아 놓기(착수) | 5줄 | 흑선, 하양이와 번갈아 3번, 다음 차례 고르기 | 완료 |
| 3 | 숨구멍(활로) | 5줄 | 가운데 4·변 3·귀 2, 상대가 붙으면 줄고 이어지면 함께 | 완료 |
| 4 | 숨구멍 하나(단수) | 7줄 | 숨구멍 1개 남은 돌 찾기, 단수 만들기 | 완료 |
| 5 | 돌 잡기(따내기) | 7줄 | 마지막 숨구멍 막기, 두 점 이상 잡기, 놓을 수 없는 곳(자살수) | 완료 |
| 6 | 도망가기(달아나기) | 7줄 | 늘어서 살리기, 잡아서 살리기, 계단 쫓기(축) 맛보기 | 완료 |
| 실전 | 따내기 바둑 | 5·7·9줄 | 하양이와 실전 (6강 전이면 배우기 안내) | 완료 |
| 7 | 이어 주기와 끊기(연결·끊음) | 7줄 | 이으면 숨구멍이 늘어남, 하양이 돌 끊기 | 완료 |
| 8 | 내 집(집) | 7줄 | 까망이 집 찾기·세기, 누구 집도 아닌 곳, 집이 많은 쪽 | 완료 |
| 9 | 두 개의 눈(삶) | 7줄 | 눈 하나는 잡히고 눈 둘은 안 잡힘, 눈 두 개 만들기 | 완료 |
| 10 | 되따기 금지(패) | 7줄 | 바로 다시 잡기 금지, 다른 곳에 두고 오면 가능 | 완료 |
| 11 | 끝내기와 세기(계가) | 7줄 | 넘기기, 집 안 하양이 돌 잡기, 돌+집 세기, 덤 | 완료 |
| 12 | 첫 바둑 한 판(대국) | 9줄 | 진짜 바둑 하는 법 → 하양이와 9줄 대국 | 완료 |
| 실전 | 진짜 바둑(집 짓기) | 9·13줄 | 하양이와 정규 대국, 집 세기 화면 (12강 전이면 배우기 안내) | 완료 |

## 5. AI 방침
- 1차는 휴리스틱 AI(따내기·단수 탈출·자기 단수 회피) 3단계. "쉬워요"는 초보다운 실수(단수 못 보기, 잡을 돌 못 보기, 비슷한 수 중 고르기)만 한다. 무작위로 아무 데나 두는 실수는 아이가 따라 배울 수 있어 쓰지 않는다.
- 정규 대국용은 휴리스틱 + 얕은 탐색부터 시작. 몬테카를로 탐색은 너무 약할 때만 쓴다. 이기고 있을 때 이상한 수를 두는 경향이 있어 아이 교육에 불리하기 때문.
- 필수 규칙: 자기 눈 메우지 않기, 둘 곳 없으면 패스, 정규 대국은 사석 정리 후 패스.
- 초반 운영: 귀 → 걸침·굳힘·받기 → 변 → 가운데(금귀 은변 초중앙). 아이가 하양이 수를 보고 배우므로 단계와 상관없이 초반은 요령대로 둔다.
- 실제 난이도는 아이와 대국해 보고 조정한다. 2026-10-26 보호자 관찰: 진짜 바둑 13줄에서 "쉬워요"에게 반쯤 이김. 하양이끼리 시뮬레이션으로는 1단계 실력이 2단계를 만나면 20% 안팎만 이겨서, 단계를 잘게 나누고 자동으로 맞춘다(2-g). 숫자는 보호자용 기록 요약으로 확인한다.

2. 무작위 대국 불변식(CI에서 1000판)
