# 바둑한수 규칙 명세 (단일 기준)

- 확정일: 2026-10-19
- 레슨·규칙 엔진·AI·계가·해설은 **모두 이 문서만** 따른다.
- 규칙 판단 코드는 `src/engine/rules/game.ts` 한 곳에만 둔다.

| 항목 | 규칙 |
|---|---|
| 기반 | Tromp-Taylor 규칙 (컴퓨터 바둑용, 예외 없는 기계적 규칙) |
| 착수 | 흑이 먼저, 교대로, 빈 교차점에만 |
| 따내기 | 착수 후 **활로 0인 상대 그룹을 먼저** 들어낸 뒤 자기 그룹 활로를 검사 |
| 자살수 | **금지** (한 점·여러 점 모두). 원래 Tromp-Taylor는 허용하지만 한·중 규칙에 맞춰 변경 |
| 반복 | **동형반복 금지(판 모양 기준)**: 착수 결과 판이 이전에 나온 판과 같으면 불법. 차례는 비교하지 않음. 단순 패도 이 규칙 하나로 처리 |
| 패스 | 판을 바꾸지 않으므로 반복 이력에 새로 넣지 않음 |
| 종료 | 연속 패스 2회, 또는 기권 |
| 계가 | 면적 계가: 자기 돌 수 + 자기 돌로만 둘러싸인 빈 곳 |
| 빅·공배 | 양쪽 돌에 모두 닿는 빈 곳은 누구 집도 아님 |
| 사석 | 자동 판정하지 않음. **판 위에 남은 돌은 모두 산 돌**로 계산 |
| 덤 | 9줄·13줄 모두 7집(백). 덤이 정수라서 **무승부가 날 수 있음** |
| 따내기 바둑 | 목표 수(1·2·3점, 기본 1점)만큼 먼저 따내면 승리. 둘 다 패스하면 무승부. 판은 5·7·9줄 |
| 정규 대국 판 | 9줄·13줄(덤 7). 19줄은 아직 넣지 않음(한 판이 너무 김). 강의 그림은 5·7줄도 쓰지만 계가 예시는 덤 없이 돌+집만 센다 |

## 운영 원칙
- 사석은 끝까지 따낸 뒤 패스한다. 면적 계가에서는 자기 집 안에 두어도 손해가 없음을 레슨에서 설명한다.
- AI도 사석을 정리한 뒤에만 패스한다.
- 양측 패스 후에는 계가 결과를 먼저 보여주고, 학습 모드에서는 재개할 수 있게 한다(무르기 활용).

## 외부 엔진과 맞출 때의 설정값 (교차 검증용)
- KataGo: `koRule=POSITIONAL`, `scoringRule=AREA`, `multiStoneSuicideLegal=false`, `taxRule=NONE`, `hasButton=false`, `komi=7`
- `@sabaki/go-board`: `preventSuicide`, `preventOverwrite` 사용. 사바키는 단순 패만 막으므로, 우리가 동형반복으로 막은 수는 "결과 판이 실제로 이전 판과 같은지"로 대조한다.
